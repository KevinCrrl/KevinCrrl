Construcción e instalación

Existen dos formas de contruir e instalar KPA: En un entorno virtual usando pip o como un paquete manejable con PacMan en un sistema de tipo Arch a través del AUR.

Usando PIP

Para instalar usando pip siga la guía en el README del repositorio de KPA

Usando el AUR

Para instalar en un sistema usando PacMan y el AUR siga estos pasos usando mkpa:

KPA depende de python-pkgbuild-parser, para automatizar la instalación de ambos paquetes se usa el script mkpa:

Descarga mkpa.sh desde el repositorio y ejecutelo como usuario NO root:

$ bash mkpa.sh install

Con esto es suficiente para que siga los pasos del script e instale python-pkgbuild-parser y kpa.
