UASPL

UASPL (Utilidad Automatizada para la Seguridad y Protección de Linux) es un programa que ayuda a automatizar la seguridad de sistemas Linux a través de los programas ClamAV, UFW, rkhunter, systemd y pkexec, todo esto a través de una interfaz de consola y un modo gráfico hecho en Python.

Este programa está disponible en el AUR. El código fuente principal está bajo la licencia GPLv3, mientras que el script complementario `uasplc` está bajo la licencia MIT.

Las siguientes configuraciones están dirigidas a la versión 2.0.0 en adelante de uaspl.

Configuración

UASPL tiene soporte para español e inglés, y un tema claro y oscuro. Por defecto usa español y el tema oscuro. Para cambiar la configuración, cree la carpeta uaspl en $XDG_CONFIG_HOME (usualmente ~/.config/uaspl), y dentro de esta cree el archivo config.json con el siguiente contenido:

{ "idioma": "espanol", "tema": "dark" }

Asegúrese de que el archivo config.json esté bien formado. UASPL ahora usa jsonschema para validar la configuración, y no se iniciará si hay un error en el archivo.

Las opciones para idioma son espanol y english.
Las opciones para tema son dark y light.

Uso de UASPL

Para usar este programa, se debe recurrir a la terminal donde existen unos cuantos comandos para usarlo e incluso activar su interfaz gráfica. Tenga en cuenta que los argumentos varían de acuerdo al idioma seleccionado en config.json.

El uso general de los comandos es:

$ uaspl [comando]

Comandos de Servicios (systemd)

UASPL ahora proporciona un control más granular sobre los servicios de ClamAV. Todos estos comandos requieren privilegios de administrador y se ejecutan internamente con pkexec:

  • Español: uaspl full-iniciar-servicios | Inglés: uaspl full-start-services: Activa e inicia inmediatamente los servicios.
  • Español: uaspl full-detener-servicios | Inglés: uaspl full-stop-services: Desactiva y detiene inmediatamente los servicios.
  • Español: uaspl estado-servicios | Inglés: uaspl status-services: Muestra el estado de los servicios.
  • Español: uaspl detener-servicios | Inglés: uaspl stop-services: Detiene los servicios en la sesión actual.
  • Español: uaspl iniciar-servicios | Inglés: uaspl start-services: Inicia los servicios en la sesión actual.
  • Español: uaspl activar-servicios | Inglés: uaspl activate-services: Activa los servicios para que inicien con el sistema.
  • Español: uaspl desactivar-servicios | Inglés: uaspl desactivate-services: Desactiva los servicios para que no inicien con el sistema.

Modo Gráfico (GUI)

La interfaz gráfica se ha mejorado. Ahora, al ejecutar un comando desde la GUI, se abrirá una nueva ventana de terminal (GTerminal) que mostrará la salida del comando en tiempo real.

$ uaspl gui

Extensiones

Guía de extensiones para UASPL.

uasplc

uasplc es un nuevo script de shell que se distribuye con UASPL. Este script se utiliza para realizar escaneos de `clamav` y `rkhunter` desde la línea de comandos. UASPL lo utiliza internamente para sus funciones de escaneo en la GUI.

El uso de uasplc es el siguiente:

$ uasplc [comando] [argumento]

Comandos disponibles:

  • clam [ruta]: Realiza un escaneo de ClamAV en la ruta especificada.
  • rk: Ejecuta un escaneo de rkhunter.
